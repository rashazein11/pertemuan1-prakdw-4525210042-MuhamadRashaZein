# Profil IMATIKA

Halaman web statis sederhana yang saya buat menggunakan HTML untuk memperkenalkan **IMATIKA (Ikatan Mahasiswa Teknik Informatika)**. Halaman ini berisi identitas organisasi, program keahlian, alur pendaftaran, dan kontak.

## Deskripsi Singkat

Proyek ini saya buat untuk menerapkan dasar-dasar HTML, seperti struktur dokumen, heading, paragraf, gambar, list, tautan, dan navigasi antarbagian dalam satu halaman.

## Struktur Halaman

1. **Header**: judul "IMATIKA" (`<h1>`) beserta slogan organisasi.
2. **Navigasi**: tautan anchor (`<nav>` dan `<a href="#...">`) yang membawa pengguna ke setiap bagian halaman.
3. **Identitas Organisasi**: logo (`<img>`), nama organisasi, alamat, dan akreditasi dalam bentuk *unordered list* (`<ul>`).
4. **Program Keahlian**: daftar program yang diurutkan berdasarkan peminat terbanyak dengan *ordered list* (`<ol>`): AI, NCS, Data Science, dan Software Engineering.
5. **Alur Pendaftaran**: contoh data pendaftaran (nama, umur, hobi, cita-cita) dalam bentuk *ordered list*.
6. **Kontak & Media Sosial**: tautan Instagram (`target="_blank"` agar terbuka di tab baru) dan email (`mailto:`).
7. **Footer**: hak cipta dan email kontak dengan tag `<small>`.

## Tag HTML yang Digunakan

| Tag | Fungsi |
|-----|--------|
| `<!DOCTYPE html>` | Menentukan bahwa dokumen menggunakan HTML5 |
| `<html lang="id">` | Elemen root dengan bahasa Indonesia |
| `<head>`, `<meta>`, `<title>` | Informasi dokumen, encoding, dan judul tab |
| `<h1>` - `<h2>` | Judul dan subjudul |
| `<p>` | Paragraf |
| `<nav>`, `<a>` | Navigasi dan tautan |
| `<img>` | Menampilkan logo |
| `<ul>`, `<ol>`, `<li>` | Daftar tidak berurutan dan berurutan |
| `<b>`, `<small>` | Teks tebal dan teks kecil |
| `<hr>` | Garis pemisah antarbagian |

## Cara Menjalankan

1. Simpan kode sebagai `index.html`.
2. Buat folder `img` di direktori yang sama, lalu letakkan file logo dengan nama `imatika.jpg`.
3. Buka `index.html` di browser (Chrome, Firefox, dll.).
